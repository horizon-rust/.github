# Horizon

Minecraft: Java Edition 26.3, rewritten in Rust: a native game that reads the same worlds, follows the same rules and
generates the same terrain as the Java game, checked against it by differential harnesses. Free, open source and
unofficial.

| Repository | What it is |
| --- | --- |
| [horizon](https://github.com/horizon-rust/horizon) | The game, the launcher, the server and the tools |
| [horizon-mods](https://github.com/horizon-rust/horizon-mods) | The registry of mods, modpacks and shader packs the launcher's mod browser lists |
